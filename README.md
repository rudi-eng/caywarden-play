# Caywarden — playable development build

Play at https://rudi-eng.github.io/caywarden-play/

This repository contains only the compiled browser game. Development source and unreleased content are maintained separately.

At Driftwood Cay, anchor and press **D** to man Fort Blackwater. Four English warships approach the open sea one at a time, from frigates to ships of the line. You have 20 cannonballs; five hits sink each ship. Mast hits damage sails, and the enemy battery can damage the fort. Aim with the mouse, click or press **Space** to fire, and press **Escape** to return to the voyage.

New voyages start with 1,000 gold. Build the first timber wall for 700 gold and mount its first cannon for 250 gold; a shipyard is not required for the fort.
